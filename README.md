# mich-pw-generator

A sleek, client-side **password generator** focused on security, control, and clean UX.

## Features
- Adjustable length (4–32)
- Uppercase, lowercase, digits, symbols toggles
- Exclude similar characters (il1|0O)
- Case preference (lower / UPPER / mixed)
- Real-time strength indicator
- Password history with one-click copy
- Fully responsive, modern UI

## Tech Stack
- HTML5
- CSS3 (custom, no frameworks)
- Vanilla JavaScript

## Usage
Open `index.html` in any modern browser.  
No install. No backend. Works offline.

## Security Notes
- Runs 100% locally
- No passwords are stored or sent anywhere
- Clipboard access via native browser API only
